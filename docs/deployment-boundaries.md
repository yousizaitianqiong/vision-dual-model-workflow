# 部署边界与安全说明

## 公开仓库边界

本仓库用于发布脱敏 Demo、协议示例和可复现测试。以下内容不属于公开范围，不应提交：

- 内部地址、服务器连接信息或本机绝对路径；
- 业务图片、视频、标注、数据库和日志；
- Qwen3-VL、SenseNova 或其他模型权重；
- API Key、Bearer Token、Cookie、密码和环境文件；
- 未经核验的准确率、吞吐量、延迟或资源占用数字。

## 真实部署建议

- 真实模型服务只绑定到经过授权的网络范围；
- Dify HTTP Request 节点使用精确的服务白名单，不扩大到整个网段；
- 生产媒体服务不接受任意远程 URL，不把用户输入拼接成命令；
- 通过容器网络、反向代理或防火墙限制模型服务和媒体服务的可访问范围；
- 使用 systemd、容器编排或等效机制托管服务，并保留脱敏日志；
- 在上线前完成模型接口连通性、冒烟测试、准确率检验和回滚预案验证。

## Demo 与生产的差异

Demo 中的两个模型服务只提取文本字段并返回示例文本，不加载权重、不读取视觉内容，也不检查图片是否到达。测试覆盖 Mock 的请求结构和 JSON/SSE 响应；Dify 实机导入、插件兼容性及媒体文件的端到端传递仍需验证。

`sensenova-si-2b` 初筛与 `qwen3-vl-8b` 复核是当前 Demo 的角色别名，不能证明真实模型型号、协议、授权或部署状态。“Qwen 初筛 + 第二模型复核”是另一个待验证方案，不能与已实现的 Mock 角色混为一谈。现有材料不足以确认租用服务器冒烟测试、准确率检验、真实模型部署或正式投用。

Compose 配置校验不证明镜像构建或容器启动成功；公开内容规则扫描通过也不保证不存在规则未覆盖的秘密或业务内容。上述检查均不能作为真实模型效果或生产稳定性的证明。
